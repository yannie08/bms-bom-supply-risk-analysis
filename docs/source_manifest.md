## Project Scope

This project analyzes the electronic component BOM, component categories, costs, alternative parts, suppliers, and supply chain risks of the Libre Solar BMS C1.

## Data Handling

The original BOM is retained as raw data. All cleaning, classification, supplier research, and risk analysis will be performed in separate files.
